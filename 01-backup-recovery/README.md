# Project 1: GCP Automated Backup and Recovery System

## Project Overview

A Python-based backup and recovery system using Google Cloud Storage.

## Technologies

- Google Cloud Storage
- Python
- Google Cloud IAM
- Google Cloud APIs

## Objectives

- Upload backup files to Cloud Storage.
- Enable Object Versioning.
- Restore previous file versions.
- Automate backup operations using Python.
